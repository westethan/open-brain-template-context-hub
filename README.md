## Overview

open-brain-template gives you a browser-based workspace for managing AI memory, rules, and active context. Instead of leaving notes, prompts, and related memory nodes scattered across separate files or conversations, it brings them into a single dashboard where they can be reviewed together.

It is built for people using MCP-compatible tools and assistants like Claude, ChatGPT, and Cursor. With Supabase and Vercel support, it suits web workflows that need a reliable structure for storing context and keeping important information within reach.

## How to use it

Begin by adding notes for the topics, rules, or context you want to preserve. Link related entries so the dashboard shows how the ideas connect as they develop.

Typical workflow:
1. Add a new memory or note.
2. Connect it to related nodes.
3. Review the visual map to follow context chains.
4. Update entries as your workflow changes.
5. Use the dashboard alongside your MCP-enabled tools to keep context aligned.

If the project is connected to Supabase, store and retrieve memory data through the configured backend while working in the browser.
